6 fallos reales y lo que me enseñaron

Lo que se rompió construyendo un pipeline DevSecOps y un homelab de Kubernetes.

Seguridad · main

Una CVE nueva tras el merge

Apareció horas después de aprobar el pull request.
La puerta funcionó: la imagen ni se firmó ni se desplegó
Seguridad · caché

La caché congeló los parches

El build reutilizaba una capa antigua de apt-get upgrade.
Una caché necesita fecha de caducidad
Kubernetes · apagado

Pasó el CI, falló en el clúster

Los pods terminaban en Error cada vez que se apagaban.
El CI no es producción: mira los códigos de salida reales
Kubernetes · reparto

Dos réplicas en el mismo nodo

La regla de reparto contaba pods que se iban a borrar.
Se arregló con una línea: matchLabelKeys
GitOps · bot

La protección de rama bloqueó al bot

GITHUB_TOKEN no puede saltarse los checks obligatorios.
Mínimo privilegio: una deploy key solo para este repo
CI · Helm

helm lint no lo vio

Una anotación numérica rompía el despliegue.
