DevSecOps Pipeline · postmortems

6 errores reales y cómo se resolvieron

Síntoma, causa y arreglo de lo que se rompió construyendo el pipeline.

Seguridad · main

Una CVE nueva tras el merge

Trivy: CVE HIGH en apt → imagen sin firmar
CausaSe publicó horas después de pasar el PR; la imagen base aún no tenía parche
Arregloapt-get upgrade en la etapa final de la imagen
LecciónLa puerta funcionó: nada sin escanear llega al clúster
GitOps · bot

El ruleset bloqueó al bot

GH013: Repository rule violations
CausaGITHUB_TOKEN no puede saltarse los checks obligatorios de main
ArregloDeploy key en el bypass + paths-ignore para evitar un bucle
LecciónCada automatismo, solo con el permiso que necesita
Kubernetes · apagado

Pods en Error en cada despliegue

exit 143 → PermissionError (exit 1)
CausaUvicorn relanza SIGTERM y la seguridad del nodo lo prohíbe
ArregloNo relanzar la señal + preStop: 0 peticiones perdidas
LecciónEl CI no es producción: mira el exit code y los logs reales
Kubernetes · helm

Anotaciones numéricas

annotations.rollout: expected string
Causa--set convierte números y el chart no los ponía entre comillas
Arreglo| quote en la plantilla. Lo detectó el test E2E en k3s
Lecciónhelm lint no basta: hay que desplegar de verdad
CI/CD · main

"EA-etn" en mayúsculas

could not parse reference: ghcr.io/EA-etn/…
Causagithub.repository conserva mayúsculas; Docker exige minúsculas
ArregloIMAGE=${IMAGE,,} al inicio del job
LecciónLo que solo corre en main también necesita pruebas
CI/CD · release

[skip ci] dejó la release sin imagen

ningún workflow para el tag v0.1.0
CausaEl commit del tag, y luego el título de un PR, llevaban la marca
ArregloQuitarla: los push con GITHUB_TOKEN no disparan workflows
LecciónEntiende el mecanismo antes de añadir algo "por si acaso"
